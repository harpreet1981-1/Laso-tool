# LassoGen
Floating lasso tool: draw around any area on screen, describe what to generate, copy/paste the HD result.

## Get the APK (no Android Studio needed)
1. Create a new GitHub repo and upload all files in this folder (keep the .github folder).
2. Open the repo's Actions tab -> "Build APK" -> wait ~3 minutes.
3. Open the finished run -> Artifacts -> download LassoGen-apk -> unzip -> install app-debug.apk.
   (Allow "install unknown apps" for your browser/files app when asked.)
